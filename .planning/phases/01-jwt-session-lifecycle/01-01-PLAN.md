## Trust Boundaries

| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Browser tab → backend API   | Every protected request crosses here carrying the bearer token; the header contract (SESSION-01) is the integrity of this crossing |
| Browser tab → local storage | Tokens persist here; logout (SESSION-05) is the erasure of this trust when a session ends                                          |

| T-1-06    | Spoofing               | direct apiClient() call sites bypassing useApi()                | medium   | mitigate    | Task 2 audits that all three bypass sites source the bearer header identically to WebAdapter.getAuthHeader(), so no site can silently drift to sending an unauthenticated or malformed request if auth-store is later touched                                                   |
| T-1-07    | Repudiation            | logout leaving a live local session after a failed network call | medium   | mitigate    | Task 3 proves useLogout() clears the local session even when POST /auth/web/logout fails, so a user cannot be left in a half-logged-out state (SESSION-05)                                                                                                                      |
